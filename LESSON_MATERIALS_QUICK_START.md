# Lesson Materials - Quick Start Guide

## Where to Find It

The Lesson Materials feature is located in **Tab 3 (Curriculum)** of the Academics module.

### Navigation Path
```
Dashboard → Academics → Curriculum Tab → Select Lesson → Scroll to "Lesson Materials"
```

### Step-by-Step
1. **Go to Academics Module**
   - Click "Academics" in the sidebar

2. **Select Context**
   - Choose an Academic Year from the Context Bar
   - Choose a Term from the Context Bar

3. **Open Curriculum Tab**
   - Click on "Curriculum / المنهج" tab (Tab 3)

4. **Select Grade and Subject**
   - Use the filters at the top to select:
     - Grade (e.g., Grade 1)
     - Subject (e.g., Mathematics)

5. **Select a Lesson**
   - In the left panel (Outline), expand a Unit
   - Click on an existing Lesson
   - The Editor panel opens on the right

6. **Scroll to Materials**
   - In the Editor panel, scroll down past the lesson form
   - You'll see a new card titled:
     - **"Lesson Materials"** (English)
     - **"مستندات الدرس"** (Arabic)

## Quick Actions

### Upload Files
1. Click **"Upload Files"** button
2. Select one or more files (max 20MB each)
3. Wait for upload to complete
4. Files appear in the list

### Add Link
1. Click **"Add Link"** button
2. Enter:
   - **Title**: Display name for the link
   - **URL**: Full URL (e.g., https://example.com)
3. Click **"Add"**
4. Link appears in the list

### Preview/Open
1. Click the **⋮** menu on any attachment
2. Select:
   - **"Preview"** for PDFs (opens in dialog)
   - **"Open"** for links (opens in new tab)
   - **"Preview"** for other files (downloads)

### Delete
1. Click the **⋮** menu on any attachment
2. Select **"Delete"**
3. Confirm in the dialog
4. Attachment is removed

## Tips

- **Multiple Files**: You can select multiple files at once when uploading
- **File Types**: All file types are supported (PDF, images, documents, etc.)
- **File Size**: Maximum 20MB per file
- **Links**: Must include protocol (https:// or http://)
- **PDF Preview**: PDFs open inline in a dialog for quick viewing
- **Closed Terms**: You can still view and preview materials, but cannot add or delete

## Keyboard Shortcuts

- **Esc**: Close any open dialog
- **Enter**: Submit in Add Link dialog (when focused on input)

## Mobile View

On mobile devices:
- Buttons stack vertically
- Action menu (⋮) provides access to Preview/Delete
- Dialogs are full-screen for better usability
- File list is scrollable

## Troubleshooting

### "File is too large"
- Maximum file size is 20MB
- Compress or split large files

### "Invalid URL format"
- Ensure URL starts with https:// or http://
- Example: https://example.com/resource

### Materials not loading
- Check that you've selected an existing lesson (not a new one)
- Refresh the page if needed

### Upload stuck
- Check your internet connection
- Try uploading one file at a time
- Refresh and try again
